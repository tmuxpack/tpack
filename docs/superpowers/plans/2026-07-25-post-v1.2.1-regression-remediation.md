# Post-v1.2.1 Regression Remediation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix reviewed configuration discovery, source graph, migration safety, and legacy wrapper regressions while preserving fail-closed cleanup behavior.

**Architecture:** Separate the writable tmux configuration from the complete ordered root list, and use a narrow tmux-aware parser to build a complete source graph. Resolve migration roots once before filesystem mutation and avoid locking when no migration candidate exists.

**Tech Stack:** Go 1.23+, tmux runner abstraction, standard library filesystem/glob APIs, Go unit/integration/E2E tests, Bash wrapper scripts.

## Global Constraints

- Implement findings 1 through 6 and 8 from the `v1.2.1..731ee39` review.
- Do not change `.goreleaser.yml`; the suggested tmux dependency is intentional.
- Preserve fail-closed cleanup whenever the active plugin graph cannot be proven complete.
- Preserve exact repository-qualified update matching; do not restore basename aliases.
- Preserve the current default writable config preference unless `@tpack-config` or a custom `tmux -f` root requires another target.
- Do not add third-party dependencies.
- Do not commit changes unless the user explicitly requests a commit.
- Run `make lint` and `make test` after code changes.

## File Structure

- `internal/tmux/tmux.go`: expose literal tmux format expansion through `Runner`.
- `internal/tmux/real.go`: execute `display-message -p -- <format>`.
- `internal/tmux/mock.go`: provide deterministic format values and errors.
- `internal/config/config.go`: define `@tpack-config`.
- `internal/config/fs.go`: add regular-file and glob operations used by discovery and source loading.
- `internal/config/paths.go`: resolve ordered read roots separately from the writable target.
- `internal/config/tmux_syntax.go`: tokenize tmux commands and identify active source directives.
- `internal/config/source_graph.go`: expand source paths and recursively load ordered matches.
- `internal/config/tmuxconf.go`: gather declarations from every source-graph document.
- `internal/plug/parse.go`: retain plugin parsing and remove obsolete source regex parsing.
- `internal/plug/migrate.go`: resolve roots and skip locking for no-op migrations.
- `bin/update_plugins`: show repository-qualified names.
- `docs/getting-started/configuration.md`: document automatic custom-config discovery and `@tpack-config`.
- `docs/troubleshooting/index.md`: replace the stale `tmux -f` workaround.
